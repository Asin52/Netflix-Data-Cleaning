Netflix Data Cleaning Using Python

Project Overview

This project focuses on cleaning and preprocessing the Netflix Movies and TV Shows dataset using Python libraries.

Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

Dataset

Netflix Movies and TV Shows dataset.

Data Cleaning Process

1. Loading the dataset using Pandas.
2. Exploring the dataset.
3. Identifying missing values.
4. Handling missing values.
5. Checking and removing duplicate records.
6. Data type conversion.
7. Data preprocessing.

Objective

To improve data quality by handling missing values, duplicates, and inconsistencies in the Netflix dataset.

Tools

Google Colab and Python libraries.
